# TOTP flyout

[English](README.md)

TOTP flyout — офлайн-аутентификатор для области уведомлений Windows. Приложение **хранит секретные ключи на диске в зашифрованном виде**, вычисляет коды на компьютере и никуда не отправляет ключи и коды. Телеметрии нет.

## Основные возможности

- Вызов из трея или сочетанием клавиш, скрытие кодов и копирование одним нажатием.
- Локальное хранилище с мастер-паролем или защитой учётной записью Windows.
- Теги, сортировка по использованию и переносимые зашифрованные резервные копии.
- Русский и английский интерфейс, автоматическое скрытие панели после копирования по желанию.

## Установка

| Версия | Файл | Как запустить |
| --- | --- | --- |
| Отдельное приложение для 64-разрядной Windows | `TOTP-flyout-setup.exe` | Запустите установщик и откройте **TOTP flyout** из меню «Пуск». Оно устанавливается для вашего пользователя. |
| Windhawk | `TOTP-flyout.wh.cpp` | Создайте локальный мод в Windhawk 1.7.3 и скомпилируйте файл в редакторе. |

Откройте значок в трее. В отдельном приложении включите **Русский интерфейс (Russian)** в настройках. В Windhawk переключатель языка находится в настройках мода. При первом запуске список аккаунтов пуст. [Как перенести ключи](IMPORT.ru.md)

## Как пользоваться

- Нажмите на аккаунт или **Enter**, чтобы скопировать код. По умолчанию коды скрыты.
- Карандаш рядом с шестерёнкой открывает сортировку и фильтр по тегам. В меню **Теги** выберите **Редактировать теги**, чтобы изменить теги выбранного аккаунта.
- В меню **Настройки → Горячая клавиша** можно включить **Alt+O** или выбрать своё сочетание с **Ctrl** или **Alt**, при желании добавив **Shift**.
- В настройках можно включить **Скрывать панель после копирования** или разрешить снимки экрана. При блокировке хранилища панель скрывается.

## Как защищены ключи

Хранилище с мастер-паролем использует AES-256-GCM. Защита Windows использует DPAPI текущего пользователя. Приложения, запущенные от того же пользователя, также могут расшифровать хранилище DPAPI. Для переноса на другой компьютер сделайте зашифрованную копию с отдельным паролем.

Хранилище блокируется по таймеру бездействия и при блокировке сеанса Windows. По умолчанию таймер установлен на пять минут. Ключи очищаются из памяти при блокировке. До очистки буфера обмена скопированный код доступен другим приложениям в вашем сеансе.

## Сборка и обновления

Сборка с Velopack выполняется командой `pwsh -NoProfile -File ./build.ps1 -Velopack`. Нужны 64-разрядная Windows, PowerShell 7.3+, Windhawk 1.7.3 и среда выполнения .NET 9. Файлы появятся в `build/release/`. Для сборки установщика с ручным обновлением опустите `-Velopack`.

В версии с Velopack нажмите на значок в трее правой кнопкой и выберите **Проверить обновления**. Приложение проверит стабильный выпуск на GitHub и попросит подтвердить скачивание. Установщик не подписан. [Как обновить приложение или вернуться к старой версии](UPDATES.ru.md)
